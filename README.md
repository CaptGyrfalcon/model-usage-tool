# AI 用量挂件（Cursor + Codex + Claude Code + DeepSeek Harness + Devin）

> **非官方 / Unofficial.** 本项目与 Cursor、Anysphere、OpenAI 均无隶属关系，也不是它们的官方产品。程序会读取本机 Cursor 登录态并调用未公开文档的账单接口，同时解析本机 Codex 与 Claude Code 会话文件。接口随时可能失效；使用本工具可能违反相关服务条款，账号存在被限制的风险。请自行判断后再使用。
>
> MIT licensed Windows widget. Not affiliated with Cursor or OpenAI. It reads local session tokens and undocumented billing APIs. Use at your own risk.
>
> **AI 辅助开发。** 本项目绝大部分代码由 AI agent 生成或辅助完成，并经人工审阅与调整。

一个常驻 Windows 通知区域的 Cursor / Codex 用量小工具。窗口不会占用任务栏位置，点右上角 `×` 只会隐藏；单击通知区域三柱图标可再次显示，右键图标可完全退出。

## 系统要求

- Windows 10 / 11 x64（目前不支持 macOS / Linux）
- [Node.js 22](https://nodejs.org/) 或更高（`node:sqlite`）
- 本机已登录 [Cursor](https://cursor.com)；Codex / Claude Code 用量需要本机有过对应会话

## 启动

双击 `start-widget.bat` 或 `启动挂件.bat`，或在终端运行：

```bash
npm install
npm start
```

请先在 Cursor 中保持登录。Codex 只要在本机使用过即可自动发现。

## 隐私与数据

- **Cursor**：读取本机 `state.vscdb` 中的登录态，调用账单相关接口。刷新后的 access token 可能写入 `%APPDATA%\cursor-usage-widget\session.json`。
- **Codex**：解析 `.codex/sessions` 与 `.codex/archived_sessions` 中的 token 计数、模型、effort 与额度窗口；不读取或保存对话正文。
- **Claude Code**：与 ccusage 相同，只读本机 `~/.claude/projects` 与 `~/.config/claude/projects`（或 `CLAUDE_CONFIG_DIR` 中逗号分隔的目录）下的会话 JSONL，含子代理记录；不使用登录凭据，也不访问任何接口。
- **DeepSeek Harness**：只读本机 `.dsh/sessions` 中的 Token 元数据，以及 `.dsh/.credentials.yaml` 中的余额查询凭据。API Key 或账号登录凭据仅在后台用于请求 DeepSeek 官方余额接口，不写入本工具设置、不传给界面，不保存对话正文。
- **Devin**：只读本机 CLI 登录配置与 `sessions.db` 的请求元数据，查询官方服务的账号每日 / 每周额度。不读取对话正文，不修改 Devin 原文件，密钥与原响应不传给界面或保存到缓存。
- **本地历史**：事件去重后写入 `%APPDATA%\cursor-usage-widget\usage-history.sqlite`，不会主动删除。
- **网络**：请求 Cursor / OpenAI / Anthropic / DeepSeek 的官方接口与价目表；DeepSeek 美元换算另查询 Frankfurter 的 ECB 历史汇率，仅发送日期和币种，不发送凭据或用量。
- 界面可开隐私模式，只把邮箱显示成 `****`，套餐名称仍会显示。删除 `%APPDATA%\cursor-usage-widget` 即可清除本应用保存的数据。

漏洞报告方式见 [SECURITY.md](SECURITY.md)。请勿在 Issue 里粘贴 token 或账单截图。

## 数据来源

- **DeepSeek Harness**：参考[官方 Token 累计实现](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/llm/token-meter/src/usage-projection.ts)，读取 `assistant/message`、`assistant/attempt` 的最终 usage（含流式 usage），输入、读缓存、写缓存、输出分别累计；同一步的重复结算替换、重试另计。分叉继承的历史不重复计入。每个会话只扫描最新格式代际；支持普通 JSONL 和 Zstandard 压缩，未完成的尾帧等待下次刷新。无法读取的会话保留历史，并提示错误。
- **DeepSeek 余额**：API Key 调用 `https://api.deepseek.com/user/balance`；账号登录沿用[Harness 官方钱包查询](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/credentials/deepseek-account-platform/src/details.ts)，调用 `https://platform.deepseek.com/api/v0/users/get_user_summary`，分别显示充值与赠送余额。失败保留最近成功余额及原采样时间，不写入虚假的零余额。余额按凭据指纹与 CNY / USD 隔离；更换凭据会开始一条独立历史，不混合不同账号或币种。

### DeepSeek Harness 接入

默认自动读取 `%USERPROFILE%\.dsh\sessions` 与 `%USERPROFILE%\.dsh\.credentials.yaml`，在 Harness 登录或设置 API Key 后刷新即可。自定义位置可设置 `DSH_HOME`；单独自定义会话目录可设置 `DSH_SESSIONS_DIR`。启动环境中的 `DEEPSEEK_API_KEY` 优先；否则优先读取官方平台账号登录记录，其次读取凭据文件中的 `DEEPSEEK_API_KEY` 和项目 / Harness 目录下 `.env`。只读原文件。

总览显示余额、充值 / 赠送构成、今日与近 30 天 Token。点余额旁的「趋势」，或在水位页选「DeepSeek CNY / USD 余额」，可切换日、周、月、年自然周期和历史周期，周从周一开始。实时余额从首次成功采样开始记录；变化包含充值、赠送及所有设备的账户消费，不能视作本机消费金额。

历史补录使用开放平台用量页的 `GET /api/v0/usage/by_api_key/amount`、`cost`、`usage/export` 和交易页的 `GET /auth-api/v0/users/get_all_invoice`，以官方 Harness 账号 grant 查询，按本地整日边界及显式时区逐月读取。补录前先用 SQLite `VACUUM INTO` 做一致性备份并校验，再在副本演练，最后以事务导入。`scripts/import-deepseek-history.cjs` 默认演练，`--apply` 导入已放在 `work/deepseek-history` 的核对资料，要求存在经哈希验证的备份记录。

平台记录是账户级模型 / API Key 日汇总，保留真实请求次数和 Token，界面明确标注“官方日汇总”；已覆盖历史日期不重复累计本机 Harness 请求，当前未结束的日期继续读取本机日志。只有日消费接口、按充值 / 赠送钱包拆分的导出账单、全部成功充值 / 赠送收入、当前两个钱包及平台累计消费全部对平，才回算已结束日期的每日余额。历史点带 `platform-ledger-daily` 来源，图表注明“官方日账单回算”，不代表当时实时采样或日内扣费时间；未对平、退款或赠送过期调整不猜测回填。重复导入不重复累计，历史点不能覆盖真实采样。

DeepSeek 同时接入模型统计、环状图、Token / 美元趋势、请求明细、小票及 CSV / JSON 导出。官方历史日账单保留实际原币金额，按消费日的 ECB CNY→USD 汇率折算美元；周末、汇率休市或当日尚未公布时使用最近已公布报价，保留消费日、汇率公布日及来源。逐 API Key / 模型 / 日期匹配实际费用，不把日账单分摊成逐对话实收。

Harness 日志只有 Token，没有逐请求实收金额。本机请求按[官方人民币单价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)估算，再换算美元，明确标为「估算」。价格核验日期为 2026-10-05，区分输入、缓存命中、缓存写入和输出，以及北京时间高峰 / 空闲时段、2026 年中国节假日；未知年份的高峰节假日状态保留费用范围。单价与汇率随首次记录保存，后续 Token 更新沿用同一依据。更早且缺少历史价表的本机记录、未知模型或汇率不可用时保持未计价，原币金额仍保留。DeepSeek 不参与订阅额度百分比、重置倒计时和耗尽预测。

### Devin 接入

本机 Devin CLI 已登录后自动发现 `%APPDATA%\devin\credentials.toml` 与
`%APPDATA%\devin\cli\sessions.db`。支持 `DEVIN_HOME`、`DEVIN_USAGE_CREDENTIALS_FILE`、
`DEVIN_SESSIONS_DB` 自定义路径。复用 CLI 同款 `GetUserStatus` 查询，只读取订阅，
不发起 agent 请求。订阅最多每分钟查询一次，失败保留原采样时间及缓存；更换凭据
会隔离额度历史。窗口过期后显示待更新，不伪造 100%。

支持总览和剩余环、日 / 周水位与周期历史、重置倒计时、耗尽预测、极简额度球、
独立用量池、托盘和任务栏额度条，以及本机请求的模型统计 / 环状图、Token / 费用
趋势、搜索明细、CSV / JSON 导出、日 / 周 / 月 / 年小票及 PNG。任务栏有 Devin
数据时增加第四行，显示日 / 周剩余；没有可靠美元容量时不显示剩余美元。

模型费用与订阅扣费分别计算。[SWE-2 官方原价](https://docs.devin.ai/desktop/models)
为每百万 Token 输入 $3、输出 $15、缓存输入 $0.30；免费期的用量图表仍按原价
显示 API 等值费用。写缓存未单列官方费率，展示估算按输入价处理。额度水位直接
使用服务端实际百分比，免费使用不扣减，恢复收费后自动跟随服务端变化。原价
每日自动检查，也可在价目表手动更新；价格快照锁定，不随活动改写已采集历史。

Token 只包含本机 CLI 数据，按请求 ID 去重工具拆分与 fork 继承，模型使用当次
请求的 `generation_model`；速度没有可靠证据时保留未知。账号额度包含其他设备
与产品。尚未采集 Desktop / Cloud 的逐请求 Token；未知模型单价保留未计价。
美元容量未知时，Devin 日 / 周独立池显示百分比，不混入总美元容量。
参考[官方免费模型额度规则](https://docs.devin.ai/desktop/accounts/quota)。

只读接入检查（仅输出状态和能力，不输出凭据或账单）：`node scripts/check-devin.cjs`。

### Cursor / Codex / Claude

- **Cursor**：读取本机 Cursor 登录态并调用账单页使用的接口，获得当前额度、逐模型事件、Token 与实际计费金额。
- **Codex**：解析本机 `.codex/sessions` 和 `.codex/archived_sessions` 中的 `token_count`、模型、effort 与额度窗口元数据；若会话记录含服务端响应 `service_tier` 则优先持久化，否则回退到 `logs_2.sqlite` / 本地会话设置中的请求 tier。不读取或保存对话正文。
- **Claude Code**：读取 `type: "assistant"` 记录的 `message.usage`（输入、输出、读缓存、5 分钟 / 1 小时写缓存）、模型、`speed`（Fast）与 effort。同一响应会拆成多行并重复同一 usage，按 `message.id + requestId` 去重。费用按 Anthropic 官方标价计算（内置价表，写缓存区分 5 分钟 1.25× 与 1 小时 2×），与 Claude Code 自身 `cost-state` 记录逐位一致；Pro / Max 订阅不按此扣费。Claude Code 每轮还会发出少量不写入会话记录的后台请求，因此比其会话总额低约 1–5%（ccusage 同样如此）。
- **Claude 额度**：读取 Claude 桌面版写在本机的 `%APPDATA%\Claude\plan-usage-history.json`（约每 15 分钟一次的 5 小时 / 7 天用量整数百分比），同步保存到本地历史，文件轮换后仍保留。这是整个账号的额度，包含 Cowork、claude.ai 网页和其他设备的用量。文件没有重置时间：窗口按「上一次 0% 采样与首个请求之间」推算起点，重置时间显示为约数并附区间。美元容量按「额度增量 ÷ 同期本机 Claude Code 标价花费」自动拟合（近 30 天，5 小时额度变化决定哪些区间干净，剔除混入其他来源用量的区间；整数取整带来的误差给出区间），并据此拆分当前窗口里本机 Claude Code 与其他来源各占多少。额度接入总览剩余环、Claude Code 卡片、耗尽预测、额度水位、额度球 / 用量池与托盘提示；任务栏暂不显示 Claude；Devin 可用时另增加第四行。
- **官方价目表**：OpenAI API 与 Cursor 模型价格每天最多自动检查一次，也可在价目表页点击「更新价格」手动更新。
- **Codex GPT-6.1 Sol 等效计价**：按官方 Standard API 普通 2×、Fast 5×；短上下文输入／缓存命中／缓存写入／输出分别为 $4／$0.20／$5／$20，Fast 为 $10／$0.50／$12.50／$50（每百万 tokens）。速度未知按普通；超过 272K 输入沿用官方长上下文比例。启动时先备份 SQLite，再仅重算本模型的历史费用，保留 token 与速度证据。此为用户指定的 Pro 5x 每周 $500 等效额度假设。
- **本地历史库**：各来源的事件都会规范化、去重后写入 `%APPDATA%\cursor-usage-widget\usage-history.sqlite`。历史事件不主动清理，远端以后缩短历史窗口也不会删除已采集的数据。

Codex 会优先采用服务端实际响应的 `service_tier`，本机当前版本未稳定落盘响应值时，使用 `priority`（Fast 请求）或 `default`（普通请求）的本地请求证据。旧版本没有该字段的事件继续显示“速度未知”，不会猜测。为了让趋势、模型汇总和套餐额度反推使用同一口径，Codex 美元等效费用采用下方用户假设价格；四个指定模型的 Fast 为 2.5×，未知按 non-fast；Cursor 价格不变。

Cursor 总览将 Cursor Grok 4.6、Grok 4.5、Composer 2.5 归入 Cursor Models 池，第三方模型归入 Other Models 池；两个池分别累计 API 等效用量并按各自已用百分比反推池总额，Other Models 同时保留 Cursor API 返回的官方套餐美元额度。

Cursor 的逐事件账单有时将 Auto 记为 `default`，不提供实际路由模型或 Fast 档位。此时工具采用事件返回的 `tokenUsage.totalCents` 计入 Cursor Models 池的 API 等效总费用，输入、缓存和输出费用标为“未拆分”，速度标为“未知”。只有历史库保留了 `chargedCents` 而原事件已无法重新获取时，才用实收金额回填，并标记为不同的计价来源。即使金额与某模型费率吻合，只要有同价模型且本地记录没有逐请求模型证据，就仍保留 `default`。

## 功能

- 账单小票：支持日、周（周一至周日）、月、年自然周期，选择周期内任一天及全部 / Cursor / Codex / Claude Code / DeepSeek / Devin 来源即可生成带供应商标志、模型名称、费用明细、Token 和缓存命中率的纸质风格小票，一键保存高清 PNG。支持独立切换按思考程度、Fast / non-fast 分组；每次切换周期重置默认值：日账单两项开启，周账单仅区分速度，月/年账单两项关闭。Composer 不区分或显示思考程度；速度未知归入 non-fast；Auto（含 default）不区分思考程度和速度。其他模型的未知思考程度单独标注，合并分组不改变总费用。按历史中已保存的 API 等效费用统计，不代表实际账单；未计价请求单独提示，不按免费计算。输入含缓存，缓存命中率为读缓存 / 全部输入；当前历史未保存可靠会话标识，因此显示请求数。

- 任务栏额度条：原生 `WS_CHILD` 控件直接嵌入 Explorer 任务栏，随任务栏一起隐藏、显示和移动。背景透明，透出任务栏本身的材质；采用 Segoe UI、圆角细进度条和轻微悬停底色，跟随 Windows 深浅色与高对比度模式。前三行分别显示 Cursor 模型、三方模型和 Codex 剩余量；有 Devin 数据时第四行显示每日 / 每周剩余百分比。右侧固定列显示剩余百分比和池内剩余美元（`余$1145.14`），进度条长度不随文字伸缩。每条进度条下方有黄色小三角，标出周期内匀速使用时当前应剩余的位置，便于平摊额度。Codex 周池与明确存在的 5h 窗口分开显示，缺失或过期数据为 `—`。双击打开小程序窗口，右键打开操作菜单；单击不打开窗口。悬停查看额度、匀速参考与采样时间。多显示器默认也在副屏横向任务栏显示，托盘菜单和应用设置可单独关闭副屏；关闭额度条本身会一并收起。自动检测任务栏应用按钮的空位，空间不足时隐藏，避免遮挡；支持 DPI 变化与 Explorer 重建后的重新挂载。

- 总览顶部为今日总 Token、今日美元等效、24 小时分时柱和各来源占比；下方每个来源一张卡片，用品牌标志、套餐和每个额度窗口的剩余环展示重置时间与耗尽风险，点击卡片展开金额拆分、拟合容量和口径说明（全屏时全部展开，迷你模式压缩为每来源一行）；未连接的来源集中列出原因；统一深色卡片、单行导航和清晰的键盘焦点
- 同步详情区分 Cursor / Codex 已同步、缓存和暂不可用，失败时保留历史，并提供加载、失败与导出结果提示
- 设置中支持开机启动、任务栏额度条、副屏任务栏和减少动态效果；默认跟随系统，隐藏窗口暂停绘制，水位过渡按实际帧间隔推进
- 请求明细支持按模型 / effort 搜索和完整 CSV / JSON 导出；导出遵循当前来源与搜索条件，没有 8,000 条上限，使用一致的数据库快照，失败时保留已有目标文件；CSV 防止文本字段被当作公式执行
- Cursor 模型 / 其他模型额度池、已用与套餐包含美元额度，以及 Codex 当前额度窗口
- Cursor 与 Codex 的美元等效费用；Codex 周额度按 Pro5x $500 / Plus $100 的用户假设显示，其他窗口保留区间估算
- Cursor + Codex 今日总 Token、最近调用和本地历史数量
- 默认每 30 秒刷新，可选 15 秒、30 秒、45 秒、1 分钟或 2 分钟
- 首次扫描本地现有 Codex 历史，此后只读取新增日志片段
- 模型用量三档统计及数据源切换：
  - **笼统**：只区分基础模型，合并 Fast 与 thinking effort
  - **速度**：区分标准 / Fast，合并 thinking effort
  - **精确**：标准 / Fast 和每一种 thinking effort 都分别统计
- 模型统计范围下拉菜单：全部历史、近 6 / 3 / 1 个月、近 14 / 7 / 1 天、近 12 / 6 / 1 小时；全部、Cursor、Codex 始终使用同一滚动时间范围

## 任务栏原生宿主

首次开启任务栏额度条时，会调用系统自带的 .NET Framework 4.x C# 编译器，将 `src/taskbar-native.cs` 与事件监听器编译到 `%APPDATA%\cursor-usage-widget\native`；后续按源码内容哈希复用。无需管理员权限、第三方任务栏补丁或 DLL 注入。Electron 仅通过本地管道发送额度行数据，原生进程负责绘制；关闭该功能或退出主程序会销毁子控件并退出原生进程。

任务栏布局变化通过窗口与按钮事件触发扫描，同一秒内合并事件；稳定布局每 30 秒做一次恢复检查。额度更新、过期检查与布局扫描独立，失败扫描会在 2 秒后重试，布局失效期间隐藏旧位置以避免覆盖任务按钮。后台采集仍按设置的刷新间隔运行；额度历史只转换、分池一次，模型统计仅在选中的不可变历史行完全一致时复用。新增、修正记录和滚动时间范围变化都会立即更新统计，不通过延长采集间隔降低 CPU 开销。

这是依赖 Explorer 窗口结构的兼容实现，并非 Windows 官方任务栏扩展接口。当前支持主屏及可选副屏横向任务栏；不会挤压或修改系统按钮布局，空位不足、UI Automation 布局暂不可读时会隐藏。Windows 更新改变任务栏内部结构后可能需要适配。

原生验证与深浅色绘制样张：

```bash
npm run test:taskbar-native
```

样张输出到 `out/native/taskbar-themes.png`。

# Codex 额度区间估算

Codex 采样使用独立来源标识保存：会话 ID、原始记录行号及内容指纹，或 HTTP 日志行 ID；相同时间戳不会互相覆盖。每条记录保留来源路径与质量标记。同一会话同一时间戳下出现不同用量内容，或采样时间落在对应周期外时，保留原记录但不用于估算和趋势。显示用的合并快照不再写回历史，各窗口保留自己的采样时间。旧 `quota_samples` 表保留作为历史存档；启用新采样后，Codex 估算读取 `codex_quota_observations` 中质量有效的原始记录。

恢复工具为 `scripts/recover-codex-quota-samples.cjs --database <目标数据库> --backup <事先备份>`。恢复前退出挂件，使用 SQLite 一致性备份并在副本上验证。工具从本机会话文件和现存 HTTP 日志重建采样，不修改请求用量记录、不删除旧采样；原始日志中缺失的真实时间不会被编造。

Fast 状态未知的请求统一按 non-fast（普通模式）计价，已有记录的计价上下界也收敛到普通模式价格。原始 Fast 状态证据仍保留为未知，已确认的 Fast 请求继续按 Fast 计价。

## Codex 假设计价与验证（2026-09-27）

这是用户指定的工作假设，不是官方套餐美元余额或账单：

| 模型 | 输入 / 百万 token | 缓存输入 | 缓存写入 | 输出 | Fast 倍数 |
|---|---:|---:|---:|---:|---:|
| GPT-6 Astra | $15 | $1.5 | $18.75 | $75 | 2.5× |
| GPT-6 Sol | $3 | $0.3 | $3.75 | $15 | 2.5× |
| GPT-6 Luna | $0.25 | $0.025 | $0.3125 | $1.25 | 2.5× |
| GPT-5.6 Sol | $4.4 | $0.44 | $5.5 | $22 | 2.5× |
| GPT-5.6 Terra | $3.5 | $0.35 | $4.375 | $21 | 2× |
| GPT-5.6 Luna | $0.35 | $0.035 | $0.4375 | $2.1 | 2× |

上述价格适用于全部上下文长度；明确 Fast 使用表中固定倍率，未知档位按普通并保留原始证据。缓存写入沿用输入价1.25倍规则。官方价格刷新不会覆盖 Codex 假设；Cursor 继续使用自己的官方价格。计价版本更新时先备份 SQLite，再按新价重算 Codex 历史费用。

Auto-review 每个完整审查 turn 收取 $0.01。通过 session ID + turn ID 去重，在 task_complete 时写入独立计费事件；同一 turn 的多条 token_count 不重复收费。未能识别完整 turn 的旧 token 记录不猜测审查次数。首次启用会先备份 SQLite 再重算 Codex 历史价格，原始 token、Cursor 费用不变。Fork 使用首条 session_meta 确定所有者，继承的旧历史不会再次计费。

Codex 额度按本周期已记录的美元消耗计算：已用百分比 = 累计美元 / 套餐额度 × 100，剩余额度 = max(0, 套餐额度 − 累计美元)。Cursor 模型池的剩余百分比使用 Cursor 服务端返回值；池内剩余美元按该百分比和配置的套餐容量换算，API 等效费用独立展示，服务端百分比暂不可用时回退到事件实收金额。金额及百分比显示两位小数，内部累计保留原精度。Codex 每周 Plus $100、Pro5x $500、Pro20x $2000；Cursor 模型池每月 Pro $450、Pro+ $1200、Ultra $3000。Codex 历史月度汇总也使用记录成本。配置容量是用户设定的展示口径，不是服务端账单；缺失或未计价记录可能少算。Cursor 三方模型池及 Codex 5小时窗口不套用这组容量。

### 独立查询与实验记录

设置面板里的“高级工具 · Codex 额度验证”提供查询一次、开始记录、结束记录和导出记录。它通过本机 Codex app-server 的 account/rateLimits/read 使用现有登录态，仅查询额度，不发起模型任务。每条查询保留请求起止时间、窗口/套餐/重置时间、整数百分比、失败状态和计价版本，不保存凭证、完整响应体或对话内容。

挂件启动后默认约每15秒主动查询 Codex 额度，无需开始实验；隐藏窗口也继续。“开始/结束记录”用于标记实验区间，结束实验不会停止后台查询。按查询开始时间安排间隔，请求不重叠；请求超时、电脑休眠或退出挂件期间会出现时间缺口，恢复后不补发积压请求。每次保留查询起止时间、成功/失败、触发来源与上次成功响应时间。15秒是目标采样间隔，并不保证服务端真实扣费时间误差小于15秒。结束记录时再查询一次；失败会保留失败状态，不伪造终点余额。近期成功主动查询优先用于展示，超过两分钟则退回明确标注的会话快照。

验证数据在 `%APPDATA%/cursor-usage-widget/codex-verification.jsonl`，状态在同目录 `codex-verification-state.json`。导出当前或最近一次实验的 JSON，包含独立额度查询、模型/token/成本明细、Fast未知数量、审批次数、失败查询和百分比变化；用量额外保留起止各120秒，以便重新调整边界。原始回退不做单调截断。输出版本号固定，可追溯假设；不会把这些新查询混入历史会话快照数据库。

推荐单一模型、Fast关闭、人工审批，开始/结束时等已有任务完成。多积累几个百分点后分析；整数取整、服务端结算延迟、其他设备消耗仍可能影响结果，采样不能获得小数精度后台余额。

### GPT-6 Sol / Luna 价格补全

已内置 2026-09-23 核对的官方价格；新模型也会从官方表自动发现。Codex 使用标准价作为等效费用基准，并沿用 Fast 2.5×、未知按普通的口径；旧模型自定义假设保持不变。已有未计价请求会自动补算，已锁定费用不随更新重算。顶栏 `$` 和价目表页「更新价格」均可手动更新；网络或解析失败会提示并保留可用价格。
